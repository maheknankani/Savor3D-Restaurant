# 🍔 Savor 3D — Interactive 3D Culinary Experience

**Savor 3D** is an interactive 3D restaurant web application built with **React 18**, **Three.js**, **React Three Fiber (R3F)**, **Vite**, and **Tailwind CSS**.

---

## ✨ Key Features

- 🎨 **Interactive 3D Food Models**: Real-time 360° rotation and zoom controls for custom 3D food models (Burgers, Pizza, Pasta, Sandwiches, Donuts, Fries, Coffee, Desserts, and Drinks).
- 🔍 **3D Food Inspector & Layer Breakdown**: Inspect dishes up close with layer-by-layer ingredient callouts, prep times, calorie counts, and customizable add-ons.
- 🪑 **3D Restaurant Floor Map & Seat Selector**: Interactive 3D floor layout featuring 4 dining zones (Rooftop Deck, Chef’s Counter, VIP Lounge, Garden Terrace) where guests click 3D tables to select their seat for reservations.
- 🛵 **Live Order Progress Tracker**: Real-time 4-step progress timeline (*Order Placed ➔ Flame Grilling ➔ Quality Check ➔ Thermal Delivery*) with live delivery countdown timer.
- 📄 **Digital Receipt PDF Generator**: Itemized digital receipt view with a one-click button to print or download PDF receipts.
- 🗣️ **AI Voice Narration**: Integrated Web Speech API audio reader that speaks dish names and descriptions aloud.
- 🛒 **Cart & Checkout Engine**: Slide-over cart drawer with quantity controls, promo code discounts, tax calculations, and celebration confetti effects.
- 🌓 **Dark / Light Mode & Custom Cursor**: Glowing interactive cursor, top scroll progress bar, and dynamic theme switching styled with Tailwind CSS & Framer Motion.

---

## 🛠️ Tech Stack

- **Frontend Framework**: React 18, Vite, Tailwind CSS, Framer Motion, Lucide Icons
- **3D Graphics Engine**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Audio & Visual Effects**: Web Speech API, Web Audio API, Canvas Confetti

## 🚀 Quick Start Guide

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Local Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
